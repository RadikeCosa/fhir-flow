- `config/fhir.config.ts`: Centraliza y valida la configuración para conectar la aplicación con el servidor FHIR R4. Define la URL base (desde la variable de entorno `FHIR_BASE_URL`), la versión FHIR, cabeceras HTTP por defecto, parámetros de paginación y las capacidades soportadas por el servidor. Esta configuración se utiliza exclusivamente en la capa de infraestructura para asegurar conexiones consistentes y seguras con el servidor FHIR.

- `types/env.d.ts`: Define el tipado estricto para las variables de entorno utilizadas en la aplicación, especialmente `FHIR_BASE_URL`. Esto asegura que el acceso a variables de entorno sea seguro y explícito en TypeScript, evitando errores por nombres incorrectos o valores inesperados. Este archivo solo contiene definiciones de tipos y no realiza validación en tiempo de ejecución.

- `lib/fhir/fhir-client.ts`: Implementa el único cliente HTTP autorizado para comunicarse con el servidor FHIR R4. Centraliza todas las solicitudes de red, usando la configuración definida en `config/fhir.config.ts`. Maneja errores HTTP y respuestas FHIR OperationOutcome de forma tipada y explícita. No contiene lógica de dominio ni mapeo de modelos; solo gestiona la comunicación y normalización de respuestas FHIR. Este cliente debe ser utilizado exclusivamente desde la capa de infraestructura, asegurando que la UI y el dominio nunca interactúen directamente con FHIR ni con la red.

- `lib/fhir/bundle-utils.ts`: Proporciona utilidades seguras para trabajar con Bundles FHIR. Emplea esquemas Zod mínimos para validar fragmentos y ofrece helpers para extraer entradas y recursos, obtener el campo `total`, resolver enlaces de paginación (`self`, `next`, `prev`) y filtrar recursos por `resourceType`. Devuelve valores por defecto en casos de bundles inválidos o faltantes en lugar de lanzar, y está diseñado para usarse en la capa de infraestructura antes de la validación y mapeo hacia los modelos de dominio.
